API Examples

Upload File

curl -X POST \ -F "file=@image.jpg" \ -F "expiresIn=24h" \ https://senacloud.my.id/api/upload

Create Paste

curl -X POST https://senacloud.my.id/api/paste \ -H "Content-Type: application/json" \ -d '{"content":"console.log(\"hello\")","expiresIn":"7d"}'

Response Format (Success)

{ "success": true, "id": "abc123", "filename": "photo.jpg", "size": 123456, "type": "image/jpeg", "url": "https://senacloud.my.id/u/abc123.jpg", "expiresAt": "2026-05-30T00:00:00.000Z" }

Response Format (Error)

{ "success": false, "message": "File type not allowed" }

FAQ

Is SenaCloud free? ▼

Yes, SenaCloud is completely free to use. Upload files, create pastes, and generate QR codes without any cost or account required.

Can I upload HTML files? ▼

Yes, HTML files are allowed. However, they will not be rendered as websites. Instead, the source code will be displayed for security and consistency.

Will HTML files render as websites? ▼

No. HTML, CSS, JS, JSON, and TXT files are displayed as source code in the browser. This prevents security issues and maintains consistency with SenaCloud's design philosophy.

How does expiration work? ▼

You can choose expiration times when uploading: 1 hour, 24 hours, 7 days, 30 days, or never. After expiration, the file is automatically deleted from the server.

Is upload history stored online? ▼

No. Upload history is stored locally in your browser using localStorage. It's only available on your device and browser. We don't store or sync history to the cloud.

Can I customize QR colors? ▼

Yes! You can choose from preset color combinations or pick custom dark and light colors for your QR code. Download as PNG and use anywhere.
