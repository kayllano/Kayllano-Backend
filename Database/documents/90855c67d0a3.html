Rules & Limitations

User Limitations
  • 1 user hanya boleh memiliki 1 active project
  • Deploy hanya 1x per minggu
  • Project dapat dihapus lalu deploy ulang
Supported File Types
  • HTML
  • CSS
  • JavaScript
  • JSON
  • Images (PNG, JPG, GIF, SVG)
  • Fonts (WOFF, WOFF2, TTF)
Upload Restrictions
  • Hanya menerima static website
  • Maximum upload: 10MB
  • Tidak boleh ada backend/server code
  • Tidak boleh ada executable files
