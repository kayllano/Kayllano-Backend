FEATURES

SOURCE VIEWER

HTML, CSS, JS, JSON, and TXT files are always shown as raw source code with syntax highlighting. HTML files never execute. Safe for sharing snippets and configs.

ZIP SHARING

ZIP files do not open raw. Instead they get a dedicated download page showing filename, size, upload date, and expiration status — inspired by Pixeldrain behavior.

DEVELOPER API

Integrate SenaCloud directly into your tools and workflows.

POST Upload File 
curl -X POST \
  -F "file=@image.jpg" \
  -F "expiresIn=24h" \
  https://senacloud.my.id/api/upload
POST Create Paste 
curl -X POST \
  -H "Content-Type: application/json" \
  -d '{"content":"Hello World","expiresIn":"7d"}' \
  https://senacloud.my.id/api/paste
