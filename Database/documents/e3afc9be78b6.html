FEATURES

SOURCE VIEWER

HTML, CSS, JS, JSON, and TXT files are always shown as raw source code with syntax highlighting. HTML files never execute. Safe for sharing snippets and configs.

ZIP SHARING

ZIP files don't open raw. Instead they get a dedicated download page showing filename, size, upload date, and expiration status.
